# 考研真题多刷记录

一个**单文件、零依赖安装**的考研真题刷题成绩记录与分析网页工具。打开 HTML 文件即可使用，数据保存在浏览器本地，支持导出备份与跨设备同步。

科目覆盖 **英语一 / 数学一 / 408 / 政治**，围绕「同一套真题反复刷」的场景，记录每一刷的各题型得分，并自动生成均分对比、涨跌趋势和题型得分率分析。

---

## 功能特性

### 成绩记录
- **多刷轮次**：每套试卷可从「一刷」追加到「六刷」，逐刷独立记录；「一刷」为基础刷次，不可删除。
- **题型级录入**：按科目预置题型拆分（如英语的完形/阅读 1-4/新题型/翻译/大小作文），录入各题型得分与分项用时。
- **自动汇总**：总分、分项小计（如英语「阅读总分」「客观题总分」）由页面自动计算。
- **总用时可填写**：「时间(分)」列可直接填写本套试卷总用时；**留空显示「其他时间」**。在题型下方填写分项用时后会自动合计到总时间，手动填写后不再被自动覆盖，清空即恢复自动合计。
- **备注与日期**：每刷可记录考试日期和文字备注。

### 统计分析
- **统计卡**：各刷均分、相邻刷次间的涨跌差值、已完成套数，随录入实时刷新。
- **多刷曲线**：横轴为试卷、每一刷一条曲线，可在「总分」与单个题型之间切换展示维度；展示总分时叠加目标分虚线。
- **题型得分率对比**：各题型按「平均得分 ÷ 满分」折算得分率横向对比，直观看出强弱项。
- **刷次筛选**：按刷次过滤统计与图表范围。

### 试卷管理
- 新增、重命名、删除试卷，拖动 `⠿` 调整顺序（顺序同时决定记录表行序与曲线图横轴顺序）。
- **「参与」开关**：取消参与的试卷不计入均分统计与曲线图，但其分数仍可正常录入，表格中以灰色标注「不参与」，适合放模拟题或不计入统计的试卷。

### 总结与计划
- 四个时间维度：**每日 / 每周 / 每半月 / 每月**，周期区间按当前日期自动对齐（周为周一到周日，半月为 1-15 日与 16 日至月末）。
- 三种条目类型：**计划 / 总结 / 二者合一**，每条可分别填写「总体」及数学一、408、英语一、政治四科内容。
- **今日计划**：首页自动汇总当天所属时间范围内的全部计划。
- **到期提醒**：时间范围结束日到达时在首页提醒该做总结或开启新一轮计划，点击可直接跳转到对应位置。
- **考研倒计时**：自定义名称与目标日期，首页以渐变发光大字显示剩余天数；进入 30 天内自动切换为紧迫配色。
- 计划模块支持 JSON 导入导出与 CSV 导出。
- 添加/编辑弹窗可拖动，支持 `↑`/`↓` 在字段间快速跳转。

### 数据与备份
- **一键备份**：把四科成绩、目标分、主题配色、总结与计划全部导出为一个 JSON 文件（文件名与内容均带当前版本号）。
- **一键恢复**：选择备份文件即可整体导回，换设备时用微信/网盘传输后恢复即可；恢复时会显示该备份的版本号。
- **版本信息**：首页「版本信息」卡片显示当前版本，可查看版本历史、导出版本记录 JSON。
- 单科支持 **CSV 导入 / 导出**（导出为带 BOM 的 UTF-8，Excel 直接打开不乱码；导入时自动识别 GBK 编码兼容旧文件）。

## 快速开始

1. 下载本目录下的 `考研真题多刷记录.html`。
2. 双击用浏览器打开。**以桌面浏览器使用为主**（记录表较宽，手机需横向滚动）；建议 Chrome 51+ / Edge 15+（代码用到 `Element.closest`、`NodeList.forEach`）。
3. 在首页点击科目卡片（英语一 / 数学一 / 408 / 政治）进入记录页，开始录入分数。

无需 Node.js、无需安装依赖、无需联网即可录入数据。**唯一可能需要网络的是图表**：ECharts 按以下顺序加载，只要其中任意一个可用即可正常绘制曲线。

1. 本地同目录的 `echarts.min.js`
2. `cdn.bootcdn.net`
3. `cdn.jsdelivr.net`
4. `cdn.staticfile.org`

若全部加载失败，页面会给出 CDN 错误提示，成绩录入与统计卡仍可正常使用，仅图表不显示。**离线使用请保留同目录的 `echarts.min.js`。**

## 使用说明

### 首页
- 顶部科目卡片进入各自的记录页，「总结与计划」卡片进入计划页。
- 下方依次是「今日计划」「总结与计划提醒」「数据备份 · 多设备同步」三块卡片，无内容时自动隐藏。
- 「总结与计划提醒」卡片右上角有**「首页提醒」开关**：取消勾选后首页不再提示「该做总结了 / 该做新一轮计划了」；关闭期间该卡片会保留（只显示开关与说明），方便随时开回来。开关状态随「一键备份」一起同步。

### 科目记录页
- **顶部工具栏**：设置目标分/国家线（图中红色虚线）、调整主题配色、添加试卷、管理试卷、CSV 导入导出、清空重来。
- **多刷曲线 / 题型得分率对比**：两张图表，随录入自动重绘。
- **成绩记录表**：按试卷 × 刷次录入。每行右侧的 `＋` 为该套试卷添加下一刷，`✕` 删除该刷（已填写内容会二次确认）。

### 总结与计划页
- 顶部切换时间维度（每日/每周/每半月/每月）与条目类型（计划/总结/二者合一）。
- 点「＋ 添加」新建条目；默认区间按**你上一轮的实际周期**顺延（上一轮 9/10–9/16 共 7 天 → 默认 9/24–9/30），修改开始日期时也按同一周期长度补齐结束日。
- 该维度还没有任何带日期的记录时，才回落到日历口径（每周=周一~周日、每半月=1~15 / 16~月末、每月=1~月末）。
- 已过期的条目会在首页「总结与计划提醒」中提示；提醒里的「新一轮」区间同样按你上一轮的周期顺延，而非自然周 / 自然月。

### 跨设备同步
1. 在旧设备首页点「一键备份」，得到一个 JSON 文件。
2. 通过微信 / 网盘把文件传到新设备。
3. 在新设备首页点「一键恢复」并选择该文件。

## 数据存储

数据保存在浏览器 `localStorage` 中，**不上传任何服务器**：

| 键名 | 内容 |
| --- | --- |
| `kaoyan_english_v1` / `kaoyan_math_v1` / `kaoyan_cs408_v1` / `kaoyan_politics_v1` | 各科试卷列表与成绩记录 |
| `kaoyan_target_english` / `kaoyan_target_math` / `kaoyan_target_cs408` / `kaoyan_target_politics` | 各科目标分 |
| `kaoyan_plan_v1` | 总结与计划数据 |
| `kaoyan_accent_<科目>` | 各科主题配色 |
| `kaoyan_countdown_v1` | 倒计时名称与目标日期 |
| `kaoyan_reminder_v1` | 首页「总结与计划提醒」开关（`1`=开 / `0`=关，**缺省为开**） |

单条成绩记录的结构大致为：

```js
{
  paperId: "p...",        // 所属试卷
  round:   "一刷",         // 刷次
  s:       [null, ...],   // 各题型得分，长度等于该科目题型数
  times:   [null, ...],   // 各题型用时（分钟）
  time:    null,          // 总用时（分钟）；null = 未填写，界面显示「其他时间」
  timeManual: false,      // 总用时是否为手动填写（false 时随分项用时自动合计）
  date:    null,          // 考试日期 YYYY-MM-DD
  note:    ""             // 备注
}
```

> ⚠️ **清除浏览器数据 / 使用无痕模式会导致记录丢失。** 清除前请先执行「一键备份」。页面内置了旧格式记录的自动迁移逻辑，历史数据可直接沿用。

## 自定义与二次开发

全部代码集中在 `考研真题多刷记录.html` 的 `<script>` 标签内，采用原生 JavaScript（ES5 风格）编写，无构建步骤。常用修改位置：

- **科目、年份、题型、满分**：`CONFIG` 对象（在 `考研真题多刷记录.html` 内搜索 `var CONFIG={`；行号会随改动漂移，故不写死）。
- **刷次名称与配色**：`ROUND_NAMES`、`ROUND_COLORS` 数组。
- **时间维度**：`PLAN_LEVELS` 数组；周期区间算法在 `dateRangeFor()`。
- **图表加载地址**：文件末尾 `loadECharts([...])` 的 URL 列表。

修改后直接刷新浏览器即可生效，无编译环节。

## 常见问题

**Q：图表不显示？**
A：多为 ECharts 未加载成功。确认同目录存在 `echarts.min.js`，或检查网络能否访问 CDN。

**Q：导入 CSV 后中文乱码？**
A：导入时已自动识别 GBK 编码。若仍异常，请用 Excel 另存为「CSV UTF-8」后重新导入。

**Q：换电脑后数据不见了？**
A：数据存在浏览器本地，不会自动跟随。使用「一键备份 / 一键恢复」迁移。

**Q：某套模拟卷不想计入均分？**
A：在「管理试卷」中取消勾选该试卷的「参与」，它就会从均分与曲线中排除。

**Q：能同时记录很多刷次吗？**
A：每套试卷最多六刷（一刷至六刷），曲线展示范围跟随所有试卷中的最高刷次。
